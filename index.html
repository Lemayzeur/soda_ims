Manage Fields

Connect each field to its sensor loggers, choose which ports to use, and set the threshold.

What is a threshold? It's the soil moisture value (VWC, m³/m³) below which a field is considered too dry. If any single port drops below this value, the field is flagged — the irrigation amount is then calculated from the average across all included ports.
Ports per logger? Some loggers have sensors on more than one port. Choose which ports to include (or exclude) per logger — useful if a port is unused, broken, or measuring something you don't want counted.
